#Interacción

Click en la parte superior del canvas activa paleta de colores frios
Click en la parte inferior del canvas activa paleta de colores cálidos
Presionar tecla [1] para aumentar el tamaño de las ventanas interiores
Presionar tecla [2] para decrementar el tamaño de las ventanas interiores
Presionar barra espaciadora para reiniciar todos los parametros
